# Vitals: utgivelser

Signerte og notariserte pakker av Vitals for testere. Kildekoden ligger i et privat repo.

- **Ny tester:** last ned `.dmg`-en fra siste utgivelse under [Releases](https://github.com/EkseMartin/Vitals-releases/releases/latest), og følg «Les meg» i den.
- **Allerede installert:** Vitals ser selv etter nye versjoner én gang i døgnet (aldri under show), sier fra med et varsel og spør før den oppdaterer.

`appcast.xml` er lista Vitals leser. Den skrives av `scripts/release.sh` i kildekoden, ikke for hånd.
